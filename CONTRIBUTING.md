# Contributing

Contributions are welcome.

Please keep changes focused on reliability, recurrence handling, Outlook compatibility, logging, testing, and safe synchronization behavior.

Before submitting a change:

1. Do not include real company names, email addresses, tenant identifiers, calendar content, or credentials.
2. Test create, change, and delete behavior in both directions.
3. Test recurring-series changes and one-off occurrence deletions.
4. Preserve the rule that attendee/organizer fields are not mirrored unless a future design explicitly and safely supports that behavior.
5. Document behavior changes in the README.

Bug reports should include sanitized logs and reproduction steps, not confidential calendar content.
